# Skalagent

시스템 상태와 내부 운영 매뉴얼을 확인해 원인 후보와 점검 방법을 안내하는 **사내 인시던트 진단 AI 에이전트**입니다. 기존 Base AI Project를 개선하고 대응 체크리스트를 추가했습니다.

## 주요 기능

- **진단 채팅**: 단일·복수 시스템 조회, 대상이 불명확하면 확인 질문
- **근거 검증**: 수치·출처·의미 검사, 검증 후 상세 답변 공개
- **대화 유지**: 기록 복원·중단 진단 재개·재조회·이전 측정값 비교
- **대응 체크리스트**: 진단 항목 저장, 상태 즉시 저장, 메모·필터·완료 현황, 중복 방지
- **실행 추적**: LangSmith로 단계별 시간·오류·검증·재작성 확인

## 실행

Python 3.11 이상을 기준으로 합니다.

```bash
bash sh/setup_venv.sh
cp .env.example .env
```

이미 `.env`가 있다면 복사 명령을 생략합니다. `.env`에 `OPENAI_API_KEY`를 입력한 뒤 실행합니다.

```bash
bash sh/run_live.sh
```

- 화면: http://localhost:8600
- API 문서: http://localhost:8100/docs
- 종료: 실행 터미널에서 `Ctrl+C` (저장 기록 유지)

기본 모델은 OpenAI `gpt-4o-mini` / `gpt-4o`입니다. 화면에서 Ollama를 선택하려면 Ollama와 `qwen3.5:2b`, `qwen3:8b`를 준비합니다. LangSmith 추적은 선택 기능이며 사용하지 않으면 `.env`의 `LANGCHAIN_TRACING_V2=false`로 설정합니다.

API 키 없이 흐름을 확인하려면 `bash sh/run_demo.sh`를 사용합니다. 데모 답변은 규칙 기반입니다. 현재 Vue 화면은 CDN 라이브러리를 불러오므로 인터넷 연결이 필요합니다.

## 구조

`Vue → FastAPI → LangGraph → 모델·MCP 조회 → 검증 → 답변`

| 경로 | 역할 |
| --- | --- |
| `web_chat.html`, `static/` | 채팅·체크리스트 화면 |
| `server.py`, `web_demo_server.py` | 백엔드 API·화면 제공 및 중계 |
| `agent/` | 요청 해석·계획·검증·저장·체크리스트 |
| `mcp_server.py` | 지표·내부 매뉴얼 조회 |
| `data/` | 샘플 상태·매뉴얼·실행 정책 |
| `sh/`, `scripts/` | 환경 준비·실행·검증 도구 |
| `tests/`, `eval/` | 자동 검사·평가 코드 및 입력 데이터 |

## 데이터와 한계

- `local-host`는 실행 컴퓨터의 CPU·시스템 메모리·디스크를 실제 측정합니다. 나머지 기본 서비스 6종은 샘플입니다.
- 현재 매뉴얼 6종은 **원문 직접 조회**합니다. RAG는 기본 비활성 상태이며 문서 확장 시 비교할 후보입니다.
- 로그·배포 이력·프로세스별 사용량은 자동 조회하지 않습니다. 이전 측정값도 요청 시점 표본이므로 지속 추세나 메모리 누수를 확정하지 않습니다.
- 서버 재시작·롤백 등의 조치는 실행하지 않습니다. 체크리스트 완료는 담당자의 수동 기록입니다.
- 로컬 단일 사용자 MVP이며 운영 환경의 권한 관리·성능 검증은 추가로 필요합니다. 외부 모델·추적 서비스 사용 시 데이터 전송 정책도 확인해야 합니다.

## 검증

```bash
.venv/bin/python -m unittest discover -s tests -q
node tests/test_markdown.cjs
```

실제 OpenAI·MCP의 지정 질문 11건에서 직전 대상 범위·검수 수정 전후 기능 점검 통과가 **7/11 → 11/11**로 바뀌었습니다. 지표·API 조건을 고정한 반복 실험이 아니므로 운영 정확도나 속도 개선율을 의미하지 않습니다. 재현 도구는 `scripts/check_responses.py`입니다.

실제 `.env`, 실행 DB, 로그, 미사용 로고, 과거 문서·캡처·발표자료와 생성된 평가 결과는 Git에서 제외합니다. `.env.example`, 런북 원문과 평가 입력 데이터는 포함합니다.
